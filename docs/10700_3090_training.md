# 10700 + 64G + RTX 3090 Training Guide

This guide is for running the stronger C++ Musesfish data pipeline and CUDA training on a Linux/Windows machine with an RTX 3090.

## 1. Clone

```bash
git clone <YOUR_GITHUB_REPO_URL> jieqi-rl
cd jieqi-rl
```

## 2. Create Environment

If you use conda:

```bash
conda env create -f environment.yml
conda activate jieqi-rl
```

If the machine needs CUDA PyTorch, install the CUDA build after activating the env. For CUDA 12.1:

```bash
pip install --upgrade torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121
```

Check CUDA:

```bash
python -c "import torch; print(torch.cuda.is_available(), torch.cuda.get_device_name(0) if torch.cuda.is_available() else None)"
```

## 3. Build C++ Musesfish

The C++ teacher is built locally; the binary is not committed.

```bash
python scripts/build_musesfish_cpp.py
```

Smoke test:

```bash
python -c "from jieqi.env import JieqiEnv; from agents.musesfish_cpp_agent import MusesfishCppAgent; env=JieqiEnv(); env.reset(seed=42); agent=MusesfishCppAgent(timeout=3,min_depth=1,max_depth=1,fallback=False); a=agent.select_action(env); print(a, a in env.legal_actions())"
```

Expected output ends with `True`.

## 4. Fast Throughput Test

Run this first to estimate data generation speed:

```bash
python -u scripts/pretrain_from_belief_mcts.py \
  --teacher musesfish_cpp \
  --games 20 \
  --max-steps 80 \
  --musesfish-cpp-min-depth 3 \
  --musesfish-cpp-max-depth 4 \
  --musesfish-cpp-timeout 2 \
  --workers 8 \
  --model resnet \
  --channels 64 \
  --blocks 3 \
  --epochs 1 \
  --batch-size 256 \
  --checkpoint-out /tmp/musesfish_cpp_smoke.pt \
  --device cuda \
  --progress-interval 1 \
  --eval-opponents ""
```

If CPU usage is stable and logs advance normally, continue with full generation.

## 5. Recommended Pretraining

Balanced speed/quality:

```bash
python -u scripts/pretrain_from_belief_mcts.py \
  --teacher musesfish_cpp \
  --games 5000 \
  --max-steps 160 \
  --musesfish-cpp-min-depth 3 \
  --musesfish-cpp-max-depth 4 \
  --musesfish-cpp-timeout 2 \
  --workers 8 \
  --model resnet \
  --channels 96 \
  --blocks 5 \
  --epochs 60 \
  --batch-size 512 \
  --cache-data data_musesfish_cpp_5000g_s160_d3d4_c96b5.npz \
  --checkpoint-out pretrained_musesfish_cpp_5000g_s160_c96_b5.pt \
  --device cuda \
  --seed 42 \
  --progress-interval 10 \
  --eval-games 100 \
  --eval-opponents musesfish
```

Higher quality, slower teacher:

```bash
python -u scripts/pretrain_from_belief_mcts.py \
  --teacher musesfish_cpp \
  --games 5000 \
  --max-steps 160 \
  --musesfish-cpp-min-depth 4 \
  --musesfish-cpp-max-depth 5 \
  --musesfish-cpp-timeout 3 \
  --workers 8 \
  --model resnet \
  --channels 96 \
  --blocks 5 \
  --epochs 60 \
  --batch-size 512 \
  --cache-data data_musesfish_cpp_5000g_s160_d4d5_c96b5.npz \
  --checkpoint-out pretrained_musesfish_cpp_5000g_s160_d4d5_c96_b5.pt \
  --device cuda \
  --seed 42 \
  --progress-interval 10 \
  --eval-games 100 \
  --eval-opponents musesfish
```

For the 10700 CPU, start with `--workers 8`. If the machine remains responsive and memory is fine, try `--workers 12`.

## 6. PPO Fine-Tuning

Start from the pretrained checkpoint:

```bash
python -u scripts/train_ppo.py \
  --init-checkpoint pretrained_musesfish_cpp_5000g_s160_c96_b5.pt \
  --model resnet \
  --channels 96 \
  --blocks 5 \
  --episodes 3000 \
  --max-steps 200 \
  --lr 1e-5 \
  --episodes-per-update 8 \
  --log-interval 8 \
  --opponent-pool \
  --opponents musesfish \
  --self-play-prob 0.0 \
  --imitation-agent musesfish_cpp \
  --imitation-coef 0.05 \
  --musesfish-cpp-min-depth 3 \
  --musesfish-cpp-max-depth 4 \
  --musesfish-cpp-timeout 2 \
  --eval-interval 100 \
  --eval-games 50 \
  --eval-opponents musesfish \
  --checkpoint-dir ckpt_ppo_musesfish_cpp_c96_b5 \
  --device cuda \
  --seed 42
```

## 7. Evaluation

Evaluate against the Python Musesfish baseline:

```bash
python scripts/evaluate.py \
  --agent-a policy \
  --checkpoint-a pretrained_musesfish_cpp_5000g_s160_c96_b5.pt \
  --agent-b musesfish \
  --games 100 \
  --max-steps 200
```

Evaluate against the C++ teacher. This is slower because the C++ agent searches every move:

```bash
python scripts/evaluate.py \
  --agent-a policy \
  --checkpoint-a pretrained_musesfish_cpp_5000g_s160_c96_b5.pt \
  --agent-b musesfish_cpp \
  --games 50 \
  --max-steps 200
```

## Notes

- Data generation is mostly CPU-bound.
- Neural network training is GPU-bound; RTX 3090 should be much faster than MPS.
- Generated `.npz`, `.pt`, and `ckpt_*` outputs are ignored by git.
- The vendored Musesfish code is GPL v3 sourced from `miaosiSari/Jieqi`; keep license implications in mind.
